<h2 align="center">Sobre mí</h2>

Soy estudiante de **Desarrollo de Software**, enfocado en la programación y en la creación de soluciones tecnológicas.

Trabajo principalmente con **JavaScript** y continúo desarrollando conocimientos en distintas áreas del software, incluyendo desarrollo Frontend, Backend, bases de datos y Data Science.

Me interesa comprender el funcionamiento de las aplicaciones, desde sus interfaces hasta la lógica del servidor, la gestión de datos y el análisis de información.
